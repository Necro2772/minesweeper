# ReactJS Minesweeper Web App

The app itself is viewable using Github Pages at https://necro2772.github.io/minesweeper/

Instructions:

The grid size can be adjusted by changing the "Width" and "Height" options, and the "Danger Ratio" option is a decimal value which decides the chance that any square will be a bomb. Changes will apply upon pressing the New Game option.

The game itself functions as a normal game of Minesweeper, following normal rules.

Controls:
Left click - clear tile
Right click - flag / unflag tile

You win if you clear all safe tiles, and you lose if you try to clear an unsafe tile.
